                     Mini Project 1: Student Profile Generator Brief

  1. Create a list of student maps with 3-5 students, each with: 
    - name
    - age
    - three subject marks.
  2. Write a function to calculate each student's average.
  3. Write a function to assign a grade/symbol based on the average.
    - A (80 +)
    - B (70 - 79)
    - C (60 - 69)
    - D (50 - 59)
    - F ( < 50 )
  4. Print a formatted report card for every student with the following details:
    - Heading
    - Student name
    - Subject marks
    - Average
    - Grade/Symbol
