# AD\_Proj1\_School\_Report

School report car Mini project



**Student Profile Report Generator**



An application that manages a list of student profiles, computes their academic performance, and outputs a formatted summary report.

This program automates the calculation of average grades from multiple subject marks and assigns corresponding letter grades according to a standardized grading scale.



**Features Profile Management**: Structures student data cleanly using core Dart collections (List<Map>).

**Performance Calculation**: Aggregates multi-subject marks and computes exact averages to two decimal places.

**Automated Grading:** Maps numerical averages to letter grades (A through F) based on defined thresholds.

**Formatted Reporting:** Outputs a cleanly padded, space-aligned console report including names, ages, individual marks, averages, and final grades.📊 



**Grading Scale:** The application evaluates student averages against the following criteria:

**Average Score   Grade**

80% and above    A

70% – 79%        B

60% – 69%        C

50% – 59%        D

Below 50%        F
